# BLOCK DRIVE 150 — iPhone & Android PWA

Бұл жоба **BLOCK DRIVE 150** ойынының орнатылатын веб-қосымша (PWA) нұсқасы.
150 деңгей, таңдалатын машиналар, 3D көрініс және локалды прогресс бұрынғы HTML-ден сақталған.

## GitHub Pages-ке орналастыру (Mac/PC)

1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `block-drive-150-pwa`).
2. ZIP архивін ашып, **ішіндегі** `index.html`, `manifest.webmanifest`, `service-worker.js`, `favicon.png`, `icons/` қалтасын репозиторийдің **түбіріне** жүктеңіз. (ZIP архивін ғана жүктемеңіз.)
3. GitHub: `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`.
4. GitHub Pages көрсеткен HTTPS сілтемесін Safari/Chrome-да ашыңыз. Ол әдетте `https://USERNAME.github.io/REPO/` сияқты болады.
5. Бірінші рет интернетпен ашыңыз. Сайттың қажет файлдары кэшке түскен соң, **сол құрылғыда** интернетсіз ашуға болады.

## Телефонда басты экранға орнату

- **iPhone:** Safari → Share → Add to Home Screen → Open as Web App (болса) → Add.
- **Android:** Chrome → ⋮ → Install app немесе Add to Home screen.

> Бағдарламаны орнату үшін жай `index.html` файлын ашу жеткіліксіз — ол HTTPS арқылы жариялануы керек. Жергілікті файл ретінде ашқанда PWA және service worker жұмыс істемейді.
>
> Ойын көлденең экранға оңтайланған. Android-та PWA manifest orientation көбіне орындалады; iPhone PWA-да экранды міндетті түрде бұғаттау барлық iOS нұсқасында қолдау таппайды, сондықтан телефонды қолмен көлденең бұру қажет болуы мүмкін.
>
> Ойын прогресі браузер/орнатылған PWA-ның жергілікті сақтау орнында сақталады. Оны өшіру, сайт деректерін тазарту немесе басқа доменге көшіру прогресті жоғалтуы мүмкін.

## Файлдар

- `index.html` — толық ойын, қосымша желілік кітапханаларсыз
- `manifest.webmanifest` — орнату және экран бағыты
- `service-worker.js` — офлайн кэш
- `icons/` — мультяшный логотиптің 192/512, maskable және Apple иконкалары

## Жаңарту

Ойынның кодын кейін өзгертсеңіз, `service-worker.js` ішіндегі `CACHE_NAME` нұсқасын да арттырыңыз (мысалы, `...-v2`). Қайта жариялаған соң құрылғылар жаңа кэшті алады.
